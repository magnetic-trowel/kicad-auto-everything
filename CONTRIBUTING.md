# Contributing

## Licensing of contributions

Contributions are licensed under the same terms as the files they touch
(inbound = outbound), as described in [`LICENSING.md`](LICENSING.md). New
source files must carry SPDX headers; new non-code material must be covered by
an annotation in [`REUSE.toml`](REUSE.toml).

## Developer Certificate of Origin

We use the [Developer Certificate of Origin](https://developercertificate.org)
instead of a CLA. Sign off every commit to certify you have the right to
submit it:

```
git commit -s
```

This adds a `Signed-off-by: Your Name <you@example.com>` trailer.

## AI-assisted contributions

AI-assisted contributions are welcome. The person signing off is responsible
for the contribution: review it, make sure it does not reproduce code or text
under incompatible terms, and follow the dependency rules in
[`LICENSING.md`](LICENSING.md) (in particular, no GPL-2.0-only or
non-commercial code, and vendor documents are paraphrased with citations, not
copied).
