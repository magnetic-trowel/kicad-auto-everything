# Test fixture board

`fixture.kicad_pcb` (with `.kicad_pro`, `.kicad_dru` and `fixture.pcbnew.json`, pcbnew's extraction of the same board) is a synthetic 4-layer KiCad 10 board made by this project for the loader tests (commit 64a6858, 2026-10-22). Its footprints come from a made-up `kae_test:` library and its rules are invented; it is not derived from any third-party design.
