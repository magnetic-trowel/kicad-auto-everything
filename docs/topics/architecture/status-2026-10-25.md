## 4. Discoveries worth keeping

- **Item order, not time, closes boards.** Freerouting stops on its own; the last connections
  fall to a different seed or to our grid router, never to a longer run.
- **The bridge had to carry every KiCad rule.** Class-pair clearances must use both coupled and
  uncoupled member pairs (diff-pair names gave a 0.25 mm HV clearance where 0.3 was required);
  KiCad's DRC escapes net names (`{slash}`) that the board file keeps; Specctra's half-micron
  rounding detaches locked stubs (pin snap).
- **The legality model must match KiCad's own source**: mask apertures over zone fills, net-less
  pads, rotated text drawn readable, copper text, custom-rule scopes. `humangate.py` (the human
  placement may produce no finding KiCad does not) caught every false positive.
- **Our placements route worse on dense sensor boards** (paw3395, pmw3610) and on split C;
  RUDY, pour fragmentation, channel and cut-capacity estimates did not predict where. Probe-select
  helps some boards; the joint loop moved paw3395 from 9 to 2 open.
- **Placer advantage from moving connectors is not real**, hence `place-fixed`.
- **Local VM** (4 cores, 16 GB) OOM-kills parallel Freerouting JVMs; kae limits slots
  (`KAE_FR_SLOTS`, default from memory/heap). On sk-tibia each attempt is sandboxed with its own
  `/tmp`, so `-j` and the memory supervisor govern.
