## Router table
Strongest open bulk router: Freerouting, even at v2.1.0 on PCBWorld → [PCBWorld](../routing/pcbworld.md#results-table-21-5). Only engine-grounded interactive primitive for LLM agents: KiCad PNS via PCBWorld-Engine. KRT and kicad-tools are agent-oriented and file-based, neither does push-and-shove [P]. With GPL-3.0-or-later code, all except GPL-2.0-only ones can be vendored or linked [I].

## KiCad, LibrePCB and the Freerouting plugin
- KiCad ships no autorouter. PNS "Attempt Finish Selected" is reachable via `RunAction` ([../kicad/built-in-automation-features.md](../kicad/built-in-automation-features.md)) [P].
- LibrePCB (GPL-3.0; 2.0.0 2026-01-28, 2.1.1 2026-06-12): no router; DSN export and SES import since 1.2.0 (2024-12-01) [P].
- Freerouting KiCad plugin: PCM version 2.4.1 ("KiCad 6.0 or newer", Tools → External Plugins; waits for the app to exit, then loads the routed design), lags upstream; SWIG support "will be removed in the next release" [P].

## Router choices for our system
- Bulk routing: Freerouting v2.5.0, pinned until 2.6.0 ships (2.6.x exists only as RCs), `-mt 1` for final runs, supervised per [../kicad/specctra-freerouting-integration.md](../kicad/specctra-freerouting-integration.md). Evaluate fastroute as a faster drop-in [I].
- Critical nets and repair: PCBWorld-Engine, linked in-process under our GPL licence or kept behind its socket for crash isolation; budget a port to KiCad 10/11 and upstreaming; pours need separate handling [I].
- Specialized jobs: KRT for fanout, diff pairs, plane repair, time matching. Use tscircuit's capacity mesh as a design reference for fast congestion estimates feeding placement [I].
- Keep DSN/SES first-class for user-supplied commercial routers [I].

## Open questions
- PCBWorld-Engine untested on KiCad 10/11; throughput and stability at scale unknown.
- route-rnd development after 0.9.3 unknown (repo.hu unreachable).
- Freerouting Docker arm/v7: README lists it; v2.2.2 notes say it was dropped.
