# Testing and evaluation practices from the KiCad MCP servers

Scope: how KMS, Konnect, PRO and POA test against KiCad; which practices and assets we reuse. Not here: our evaluation stack -> `verification/` area ([../verification/harness.md](../verification/harness.md)); transform oracles -> [transform-math-pitfalls.md](transform-math-pitfalls.md).
Keys: independent judge, pcbnew_judge, kicad_ref, test ladder, negative control, golden corpus, tool-selection evals, expected_tools, forbidden_tools, max_calls, attempt accounting, pcb-task-outcome.v1, infrastructure_invalid, manual_repair, MagicMock, KICAD_USE_REAL_PCBNEW, routing harness, Hypothesis, CI matrix

**Strongest strategy (POA):** "Every test has a judge that is not the code under test": KiCad's own Python, `kicad-cli` output, ports of KiCad routines, or exact integer geometry. **Weakest (KMS):** tests against `MagicMock` pcbnew stubs [P]. No server publishes placement or routing quality results on a board corpus; PRO's reference-board corpus is infrastructure only: it "does **not** by itself satisfy the requirement to publish at least three serious reference boards" [P].

## What we adopt
[I]
- **Practices:** an independent judge for every test; a negative control for every guard; a `kicad-cli` load check on every produced file; drill and Gerber coordinate oracles for every transform; netlist node-set diffs around every mutating call; a KiCad 9 and 10 CI matrix.
- **Reuse:** POA `pcbnew_judge` and `kicad_ref` (GPL-3.0-or-later, compatible with our code); PRO golden corpus and eval scorer (MIT); Konnect live-DRC recipe as a pattern only (AGPL; reimplement).
- **Fixtures:** read KiCad's shipped demos (ecc83, pic_programmer, multichannel_mixer, vme-wren; CC BY-SA 4.0) from the user's install, as POA does, rather than re-hosting; Antmicro's Apache-2.0 boards for routed ground truth ([../licensing/data-rulepacks-weights.md](../licensing/data-rulepacks-weights.md)).
- **Benchmark contract:** PRO-style attempt accounting + tool-selection evals; the evaluation stack itself belongs to `verification/` ([../landscape/measured-tool-comparisons.md](../landscape/measured-tool-comparisons.md) for public results).
