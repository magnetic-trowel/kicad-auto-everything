Scope: 33 methods from other fields mapped to PCB placement/routing, ranked by expected payoff vs effort (H/M/L; judgment calls from the notes, not measurements); xd#N = row N. Detail in the linked topic docs; test status in [research/ideas](../research/ideas.md#cross-domain-transplants-33); one-line inventory entries: [inventory-algorithms §V](inventory-algorithms.md#v-cross-domain-transplants).
Keys: transplants, xd#, PCB-PSDL, LayoutVLM, VeoPlace, VLM judge, sparrow, jagua-rs, HOLA, IPSep-CoLa, polygon MCTS, AlphaEvolve, QD, MAP-Elites, diffusion placer, map labeling, sequence pair, DEE, homotopy, MAPF, CBS, ASP/WFC, SAT/ZDD, stakeholder critics
Evidence: [P] primary full text, [S] snippet/abstract. Ranking shaped by consistent negative evidence: LLMs fail at direct MAPF, crossing-free drawing beyond tiny graphs (PlanarBench), long relative-reference chains (R3L) and free-form constraint modeling (Text2Zinc ≤25%), so the LLM supplies **intent, structure, topology, priorities and critique**, and solvers produce geometry repaired near that intent.

## Composite architecture and gaps

**Composite architecture suggested by the ranking** [I]: board plan (blocks, VLM regions, relations) → PCB-PSDL program from skill-library macros → LLM-free repair (fallback: hybrid projected-gradient placer seeded by HOLA/IPSep) → sparrow-style legalization + DEE orientations → silkscreen labeling → polygon-MCTS or PathFinder routing guided by LLM priorities and homotopy hints, SAT windows for hard escapes → VLM pros/cons ranking + QD portfolio with histograms → offline AlphaEvolve-style heuristic evolution → long-horizon diffusion prior. See [recommended stack](../topics/solvers/recommended-stack.md).

**Gaps**: no head-to-head PCB benchmark of these transplants (PCBWorld may serve); licences of Holodeck, LayoutVLM, Adaptagrams and DATE router code unverified.
