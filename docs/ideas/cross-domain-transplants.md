# Cross-domain transplants for LLM-driven PCB placement and routing (ranked)

Ranked by expected payoff vs effort (H/M/L; judgment calls from the notes, not measurements). Evidence: [P] primary full text, [S] snippet/abstract. Detail lives in the linked topic docs. Consistent negative evidence shapes the ranking: LLMs fail at direct MAPF, crossing-free drawing beyond tiny graphs (PlanarBench), long relative-reference chains (R3L) and free-form constraint modeling (Text2Zinc ≤25%) — so the LLM supplies **intent, structure, topology, priorities and critique**, and solvers produce geometry repaired near that intent.
