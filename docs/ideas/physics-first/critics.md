# Physics-first ideas: critics and metrics (PC)

Scope: PC1–PC44, ideas for measuring "physically right" so DRC-clean but physically wrong boards are caught, scored and fed back to optimizers and the LLM. Not here: critic design and catalog -> [physics-critics](../../topics/physics/physics-critics.md), [catalog](../../topics/physics/physics-critics-catalog.md), [validation](../../topics/physics/physics-critics-validation.md).

## A. Shared infrastructure

- **PC1** Board physics model (BPM) (*combo, M*). Computed once per board: copper layer z and h, per-layer reference map (fills by net), current-return graph (pads, tracks, vias, pours as resistive/inductive graph), plane polygons and slot list, via spans; critics read the BPM instead of re-parsing; edits invalidate only affected tiles. Consistency bugs ("checks that disagree with KiCad") come from re-implementations. Test: identical critic results via BPM and standalone parsing on 20 boards.
- **PC2** Refill-then-measure contract (*sharp, S*). A critic run starts with `kicad-cli pcb drc --refill-zones --save-board` on a private copy and records the fill hash. Stale fills are the commonest silent error ([why](../../topics/physics/physics-critics.md#4-fitting-it-into-kaebench-without-touching-the-score)). Test: FILL-STALE never non-zero in recorded runs.
- **PC3** Continuous quantities, thresholds only in the scorecard (*sharp, S*). Critics report nH, mV, mm, GHz with attribution, never pass/fail; budgets convert to utilization in one place; gives optimizers gradients, removes cliffs (via at 1.99 mm vs a 2 mm rule). Test: metamorphic ±0.05 mm nudges change every score continuously.
- **PC4** Tri-state per check: measured / not checked / out of trust (*combo, S*). Every critic × object pair states whether it ran and whether the proxy is inside its calibrated region; scorecard reports coverage first ("a check that didn't run reports zero"). Test: inject missing roles and stackups; scorecard must show reduced coverage, never a cleaner score.
- **PC5** Role-model freeze (*sharp, S*). Net roles, t_r, currents, connector classes fixed per task like DRC rules, installed by the scorer; otherwise a method relabels a cable connector as internal or a clock as slow and passes every EMI critic. Test: red-team role edits change nothing in the score.

## B. Return path, reference and EMI critics

- **PC6** RPQF-lite, a return-path quality factor from closed forms (*sharp, S*). L_est/L_ideal per net from microstrip L′ per piece, far-plane hops, edge crowding, void detours (shorted slot-line), via or cap bridges; ms per net, every candidate ([RET-RPQF](../../topics/physics/physics-critics-catalog.md#a-return-path-and-reference-structure)). Test: rank correlation with FastHenry full-net loop L on 100 nets.
- **PC7** Return-current shadow map (*new, M*). Render predicted return-current density per reference (1/(1+(x/h)²) profile clipped to copper, detoured around voids by 2-D Laplace) and diff with the ideal shadow; voids show as displaced current, readable by critics and a VLM judge. Test: vs openEMS surface-current dumps on 10 slices.
- **PC8** Plane perforation index (*sharp, S*). Per declared plane: foreign track length, longest slot and its half-wave frequency, island count; catches "signals through the GND plane" directly, 1 ms in the prototype. Test: M-TRACE-IN-PLANE detection 100% in the prototype run.
- **PC9** Connectivity-qualified reference (*sharp, S*). A fill counts as reference only if connected to the reference net and stitched within d of the trace; floating or poorly stitched patches stop faking coverage. Test: red-team "cosmetic pour" edits no longer improve RET-COV.
- **PC10** Bridging-cap return estimator (*sharp, S*). At a layer change that switches reference net, find the nearest capacitor between the two nets; estimate plane-pair spreading + mounting L; report nH and ground-bounce mV at the net's dI/dt; replaces "stitching cap within X mm". Test: FastHenry on 20 transitions; estimate under-reads Ott ([calibration gap](../../topics/physics/physics-critics-validation.md#open-questions)).
- **PC11** Ott-anchored slot severity (*sharp, S*). Severity ΔV ∝ ℓ·ln(ℓ/ℓ0) fitted to Ott, and a g/h-dependent slot-line Z ([worked fits 1–2](../../topics/physics/physics-critics-validation.md#calibration-references-f3-and-measurement)). Test: openEMS sweep of slot length and width under a 50 Ω line.
- **PC12** Spectral coincidence critic (*new, M*). List structural resonances (plane cavity, slot half-waves, island quarter-waves, via stubs) and excitation lines (clock and switching harmonics up to f_knee); score overlaps in dB. A resonance matters only if driven, so this beats blanket λ/20 stitching. Test: openEMS resonance list vs critic list on 5 boards.
- **PC13** Connector-pair common-mode ledger (*combo, M*). Per cable-connector pair, sum MREMC V_cm of all fast nets whose return crosses between them; charge against 1 mV (Class B) or 100 µV (strict); the cable pair is the antenna below ≈100 MHz. Test: pre-scan of coupons with planted connector splits.
- **PC14** Edge-proximity as inductance (*sharp, S*). Return-plane L increase from the MREMC offset formula instead of "3h from the edge" ([RET-EDGE](../../topics/physics/physics-critics-catalog.md#a-return-path-and-reference-structure)). Test: openEMS fringing at 5 edge distances.
- **PC15** Aggressor–victim noise matrix (*combo, M*). Per victim role (sense, FB, analog, I/O, clock) sum coupled mV from every aggressor role (SW node, hot loop, clocks, high-current lines) using K, run length, broadside overlap, loop mutual L; "keep high-current lines away from differential pairs" becomes a budget. Test: 2-D solves of 30 coupled sections.
- **PC16** Diff-pair imbalance localizer (*sharp, M*). Diff the two legs feature by feature (vias, bends, reference changes, neck-downs); report where mode conversion happens, not only total skew (local imbalance radiates at zero total skew). Test: openEMS Scd21 on pairs with planted asymmetric vias.

## C. Power and PDN critics

- **PC17** Hot-loop L from realized copper (*combo, M*). Extract the commutation path the current really takes (pads, pours, vias, plane below), partial L by coarse PEEC/FastHenry; overshoot = L·di/dt vs 0.2·V_DS,max. Pad-centroid shoelace areas miss returns through far planes or via detours. Test: AN-139, SNVA803, EPC anchors as regression points.
- **PC18** Decap effectiveness as impedance at the pin (*sharp, S*). Per power pin, loop pin → via → plane pair → cap vias → cap gives |Z| in the pin's band; replaces "decap within 3 mm" ([DECAP-L](../../topics/physics/physics-critics-catalog.md#c-power-pdn-and-commutation)). Test: M-DECAP-FAR detection; FastHenry spot checks.
- **PC19** Current-density hotspot map (*combo, M*). Sparse 2-D Laplace per rail per layer, vias as resistors: drop, peak J, via current sharing; finds via-field "Swiss cheese" necks and starved thermal reliefs a width rule cannot see. Test: padne/KiPI agreement; M-NECK, M-THERMAL-RELIEF detection.
- **PC20** Via-field min-cut screen (*new, S*). Before Laplace, min conductive cross-section along each source-to-sink path (max-flow min cut on a copper raster), ms runtime, flags merged antipads that neck a pour. Test: rank agreement with J-MAX.
- **PC21** Sense-loop mutual inductance (*new, M*). Neumann integral with plane images between hot loop (or SW copper) and each FB, current-sense or Kelvin loop; induced mV = M·di/dt vs sense budget; FB keep-out becomes computed. Test: FastHenry mutual L; M-SENSE-PARALLEL detection.
- **PC22** SW-node displacement current (*sharp, S*). C of switch-node copper to every plane and neighbour × dV/dt = injected mA; each extra mm² has a price. Test: 2-D C extraction on 10 converters.
- **PC23** Kelvin tap error (*sharp, M*). Shared R between sense tap and main current path from Laplace potentials gives error in mV and % of shunt signal. Test: M-KELVIN-MOVE.
- **PC24** Ground-as-traces detector (*sharp, S*). GND/power pins reaching their plane only through thin traces, scored by R and L to the plane vs the rail's current budget, not a width cut (OmniRouting failure mode). Must know rail current: a real board's filtered +3.3VA rail ran 79 mm of thin trace on purpose. Test: M-GND-TRACE; false alarms on filtered analog rails.

## D. Thermal, high voltage and manufacturing physics

- **PC25** Copper-graph thermal screener (*combo, M*). 2.5-D resistive network from actual copper and vias ([THERM-DT](../../topics/physics/physics-critics-catalog.md#e-thermal-high-voltage-manufacturing-physics)), power per part from the role model, on every candidate; replaces "big pad, many vias" with ΔT. Test: Elmer on 10 boards; thermal camera on coupons.
- **PC26** Thermal-victim critic (*sharp, S*). ΔT at crystals, references, sensors, electrolytics from nearby dissipators vs each victim's drift or life budget (electrolytic life halves per +10 °C). Test: M-HOT-NEIGHBOUR.
- **PC27** HV field map with corner enhancement (*combo, M*). Peak V/mm between different-potential copper incl. inner layers and acute corners from a 2-D electrostatic solve on candidate regions; creepage tables cover the surface, this covers laminate and points. Test: FEniCS/Elmer reference on 10 geometries.
- **PC28** Warp and tombstone physics (*sharp, S*). Copper balance between mirrored layers (CTE mismatch) and thermal-mass asymmetry between the pads of small passives: cheap assembly checks, the only manufacturing physics most boards need. Test: correlation with assembler defect reports where available.

## E. Trust: mutation, calibration and gaming

- **PC29** DRC-equivalent mutation benchmark (*new, M*). Faults that keep `kicad-cli` DRC counts identical (pour keep-out slots, deleted stitching vias, swapped plane nets, moved decap vias, traces moved onto plane layers); measure each critic's detection and false alarms: ground truth DRC scores cannot give. Test: the benchmark itself, ≥ 8 operators × 50 boards.
- **PC30** Physics-labelled mutants (*sharp, S*). Label each mutant's delta with an oracle (F1 everywhere, F2/F3 on a sample); sub-resolution deltas are equivalent mutants; score improvements and regressions per net. "Mutated" ≠ "worse": swapping plane nets improved some nets on a real board. Test: F1 vs F3 label agreement on the sample.
- **PC31** Benign twins (*sharp, S*). Each operator has a no-physics-delta control edit (far slot, extra GND via, collinear split, whole-board rotation); false alarms measured on twins, not only clean originals. Test: prototype's controls raised no new findings.
- **PC32** Metamorphic tests for critics (*new, S*). Results invariant under translation, rotation, mirroring, segment splitting, net renaming; continuous under ±0.05 mm nudges; catches parser and transform bugs, the commonest class in field reports. Test: all qualified boards in CI.
- **PC33** Per-critic red team (*combo, S*). Before a critic enters any reward, an adversarial agent gets its API and tries to raise the score without physics gain (cosmetic pours, vias landing on one plane, 6° jogs, role edits); each hack becomes a regression test ([V2](../original/verification.md)). Test: hacks found per critic version.
- **PC34** Disagreement-driven calibration (*combo, M*). When F1 and F2 disagree beyond tolerance on a candidate, escalate and keep the pair as a calibration point; proxies improve where the optimizer goes ([V4](../original/verification.md)). Test: proxy error on optimizer-visited states before/after.
- **PC35** Windowed field-solver spot checks (*combo, M*). Simulate only a 10 × 10 mm window (openEMS or FastHenry) around each board's top-k findings: minutes, vs unaffordable full-board solves. Test: window vs full-slice agreement on 10 cases.
- **PC36** Physics unit boards (*combo, S*). Tiny generated boards each isolating one mechanism (slot crossing, layer change, decap loop, edge run, cavity) with an analytic answer: unit tests for every critic and a teaching set for the LLM. Test: critic error vs closed form and openEMS.
- **PC37** Coupon campaign for EMI and thermal ground truth (*new, L*). Fabricate 5–10 coupons with planted faults and their twins; measure near-field scans, VNA S-parameters, thermal images; only way to calibrate CM-V and LOOP-RAD (no open dataset covers them). Test: the campaign itself.

## F. Reporting and the repair loop

- **PC38** Physics markers in drc.v1 shape (*combo, S*). Findings in DRC's JSON shape (type, severity, description, items with uuid and pos) plus measured, limit, unit, budget_id, top spenders; LLM repair loop and DRC tooling read them unchanged. Test: an LLM repair loop fixes planted faults from markers alone.
- **PC39** Root-cause grouping (*combo, S*). One plane cut causes a dozen crossing markers; group by causing copper feature (slot polygon, missing via) before showing the LLM. Test: repair success grouped vs ungrouped.
- **PC40** Parametric repair hints (*combo, M*). Markers carry IR-level fixes ("add a GND via within 1.5 mm of (x, y) on both planes"; "move segment uuid to the layer referenced to GND") so the LLM edits intent, not copper. Test: share of findings fixed in one step.
- **PC41** Physics diff between two boards (*new, M*). Per-budget deltas with attribution ("+1.2 nH: GND via of C12 moved 4 mm") so reviewers and the LLM see an edit's cost. Test: reviewer time on 20 diffs.
- **PC42** Human-relative physics (*sharp, S*). Score the human reference with the same critics; report regressions relative to it, separating board-inherent from router-induced issues. Human boards are imperfect: the prototype found USB lines on three of four boards changing reference between GND and a power plane at vias. Test: router audit in [physics-critics](../../topics/physics/physics-critics.md).
- **PC43** Physics best-of-k as a separate column (*new, S*). "cpk-phys" = best clean attempt by physics scorecard, beside cpk, never replacing it ([report](../../topics/physics/physics-critics.md#4-fitting-it-into-kaebench-without-touching-the-score)); shows whether k attempts buy physics. Test: cpk-phys vs cpk on the Freerouting baseline.
- **PC44** Layer-type hygiene probe (*sharp, S*). Sampled boards type planes `signal`, so Freerouting may route through them ([prediction](../../topics/physics/physics-critics.md#5-the-drc-clean-but-physically-wrong-benchmark)). An adapter variant marking declared planes `power` in the DSN measures how much plane perforation that alone removes; new adapter and run name, changes the method, never the score. Test: PLANE-PERF on Freerouting outputs with/without.
