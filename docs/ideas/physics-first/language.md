# Language ideas: a shared physics vocabulary for layout (LA1–LA52)

Scope: ideas for the physics vocabulary and IR (`pcb-intent`): ports, loops, bands, budgets, operators, glyphs, compilation. Not here: concept definitions -> [vocabulary](../../topics/physics/vocabulary.md); schema -> [physics-ir](../../topics/physics/physics-ir.md); six worked circuits -> [physics-ir-examples](../../topics/physics/physics-ir-examples.md).
Keys: LA1–LA52, half-port, required/observed twin, designed/parasitic flag, node–loop duality, band netlist, spectrum envelope, exclusion zone, sense port, Kelvin, commutation cell, halo, magnetic moment, operator card, glyph, spender bar, FastHenry deck, entity stamp, mutant

- Builds on, does not repeat: budget ledger, dimensioned types, why-graph (I1–I3, [intent-and-why](../original/intent-and-why.md)). Where another catalog owns the computation (RG [rule-replacements](rule-replacements.md), XD [cross-domain](cross-domain.md), JPR [joint-place-route](joint-place-route.md)), the LA idea is the *language handle*.
- Tags: **new** (not in corpus), **combo** (known pieces combined), **sharp** (existing idea given a number or test). Effort S days, M weeks, L months. [C] numbers from `tools/research/physics/vo_*.py`.
- Build first: LA1 half-port promotion, LA12 band netlists, LA7 current exclusion zones, LA30 operator sensitivity cards, LA39 mechanism hypotheses as the LLM's main write.

## A. Atoms and grammar

- **LA1** Half-port promotion (*new, S*): before placement, promote every net touching an IC pin, connector or cell to a Port with named reference terminals (nearest return pins from IBIS `GND`/`POWER` or the pin-role ontology, receptacle GND pins, the cap's other pad); unpaired net → "half-port" finding the LLM must resolve. A schematic says nothing about return current; FastHenry refuses a port with no return path (NaN impedance) [P]. Test: do half-port findings on 20 open boards predict RET-COV/RET-VIA failures ([critic catalog](../../topics/physics/physics-critics-catalog.md))?
- **LA2** Required/observed twin relations (*sharp, S*): each relation exists required (`intent.yaml`) and observed (`ledger.json`); critics are set diffs ("required `returns_through(usb.sstx, ref.l2)`; observed 38% via In3.Cu after the connector"). Test: seeded-fault exams (V3), time to root cause, diffs vs DRC lists.
- **LA3** Designed/parasitic sign flag (*new, S*): one kind set covers PCB antenna/unintended antenna, shunt trace/parasitic R, heat spreader/switch node; `intent: designed` flips the objective (budget → spec); one ontology, one solver stack. Test: express 10 designed structures (IFA, PCB shunt, spiral inductor, spark gap, guard ring, fuse trace, Rogowski trace, thermal pad, CPWG, Kelvin bar) with no new kinds.
- **LA4** Node–loop duality typing (*new, S*): type each aggressor/victim as dv/dt Node (E-field, capacitive, voltage-driven CM) or di/dt Loop (B-field, inductive, current-driven CM); each operator declares a signed effect on each. "make it wide" helps the loop, hurts the node ([buck SW node](../../topics/physics/physics-ir-examples.md#1-synchronous-buck-12-v--33-v-3-a-1-mhz-integrated-fets)) [C]. Test: 30 converter layouts, node+loop score vs area alone against near-field EMI.
- **LA5** Antennas must name two halves (*sharp, S*): grammar refuses "this trace radiates" without two electrically large conductors and the V or I between them (LearnEMC antenna model, [emc-placement](../../topics/rules/emc-placement.md)) [P]; candidates generated for every pair of external port references, heatsinks, shields, each with V_cm budget (1 mV) or I_cm budget (5 µA, Ott Class B). Test: mechanism precision, CM-V critic vs free-text LLM EMI review, 20 boards.
- **LA6** Common impedance names its shared conductor (*sharp, S*): `common_impedance` must name `shared:`; ledger reports R, L of the shared segment from partial elements. 24-bit ADC: the shared-reference budget is far below any pour ([numbers](../../topics/physics/physics-ir-examples.md#4-24-bit-bridge-adc-front-end-ratiometric)) [C] → topology change, not a wider trace. IR form of RG18. Test: re-explain 20 forum ground-loop post-mortems.
- **LA7** Current exclusion zones (*new, M*): `exclusion(region, of, band, J_frac)` replaces "split the ground"; checker solves DC/LF current density of the named aggressor loops (sheet-resistance Laplace below f_x) and integrates over the victim's reference region. Below f_x ([bands](../../topics/physics/vocabulary.md#bands-and-regimes)) current spreads resistively, so placement + solid copper keep it out without a slot. Test: 10 mixed-signal designs, solid + exclusion vs split, ADC-reference µV by 2D solver and RET-COV for HF nets.
- **LA8** Sense ports with tap points (*sharp, S*): `use: sense` adds `I_through == 0` and a body tap point (`R70.1@inner_edge`), compiled to a net tie + checker that the tap segment carries no load current; generalizes Kelvin to FB, remote sense, references, shunts (computation: XD72). Test: 2D tap error vs position on 20 shunt footprints; vs the solder-error estimate in [half-bridge](../../topics/physics/physics-ir-examples.md#6-48-v-half-bridge-motor-phase-with-low-side-shunt) [C].
- **LA9** Cell templates as typed molecules (*sharp, S*): one commutation-cell schema (switch pair, HF cap, SW node, gate loops, Kelvin points, shunt) covers buck, boost, half-bridge, flyback primary, class D, motor phases; templates as data. XD12 = cell as placement unit; LA9 = language unit. Test: encode the [hot-loop table](../../topics/rules/power/hot-loops.md) with one schema; count special cases.
- **LA10** Mechanical ports carry EM roles (*sharp, S*): MCAD connectors, heatsinks, mounting holes, shield cans become fixed ports/bodies with EM roles: chassis bonds = where CM current leaves; heatsinks = capacitors to chassis ([tab C](../../topics/physics/physics-ir-examples.md#6-48-v-half-bridge-motor-phase-with-low-side-shunt)) [C]. Test: CM-V predictions with/without bond locations, 10 cabled boards.

## B. Quantities, bands, regimes and spectra

- **LA11** Regime per structure, not per board (*sharp, S*): ledger stores regime per (structure, band): one net is R-regime at 50 Hz and L-regime for its edges. RG2 supplies groups; IR attaches them and gates packs with `applies_if: {regime}`. Test: rules whose verdict changes per-structure vs per-board.
- **LA12** Band netlists for loop discovery (*new, S*): per band replace parts by band models (caps with |Z| < threshold → shorts, inductors/beads → opens, switches both states); the graph's cycle basis yields hot, decoupling, gate and snubber loops without templates; the hot loop is a cycle in the HF graph. Test: recover hot-loop membership for 30 converters vs hand labels.
- **LA13** Spectra as log-log envelopes (*sharp, S*): store breakpoints (trapezoid corners 1/(πτ), 1/(πt_r), ring peaks) and coupling transfers as envelopes; the N² aggressor × victim screen = envelope addition in dB. Test: 10 cells, envelope vs SPICE verdicts, false negatives.
- **LA14** Spectra as a fixed point (*new, M*): layout → parasitics → spectrum → budgets → layout, 2–3 iterations with excitations back-annotated from a layout-aware cell model. SW ringing set by L_loop and C_oss, not the clean trapezoid, dominates at 2.45 GHz ([feed](../../topics/physics/physics-ir-examples.md#5-24-ghz-antenna-feed-soc--π-match--chip-antenna)) [C]. Test: verdict changes across iterations, 10 converter + radio boards.
- **LA15** Budgets on uncertainty, not value (*new, S*): intervals (`[1.0 pF, 2.2 pF]`) spend only the unknown part; a known crystal stray is absorbed by choosing CL ([crystal](../../topics/physics/physics-ir-examples.md#3-32-mhz-pierce-crystal-for-an-802154-radio)) [C]; same for offset trims, impedance tolerance. Test: large well-known strays pass where the mm rule fails.
- **LA16** Victim sensitivity includes its own rejection (*sharp, S*): thresholds carry the victim's transfer (sigma-delta sinc, PSRR, CMRR, anti-alias RC); MHz coupling into a 10 SPS ADC is mostly rejected, DC/LF common impedance, heat and alias bands are not. Avoids area-costly over-separation. Test: couplings dropped/kept on 10 mixed-signal boards, sample by simulation.
- **LA17** Dimensional lint with feedback (*sharp, S*): `vo_ir_check.py` catches 12/12 seeded errors (half-port, open loop, pF for nH, capacitive coupling from a loop, unknown band, missing shared conductor, unlike dimensions, alloc > 100%, unknown key, bare numbers) [C]; make it a mandatory pre-submit LLM tool with fix-naming errors. Test: authoring error rate on 200 LLM IR files with/without.
- **LA18** The LLM writes expressions, never resolved numbers (*sharp, S*): `0.85*V_abs(U3.VIN)`, `lambda_g(2.48 GHz, F.Cu)/20` instead of "17 V", "3.4 mm"; stackup/part changes re-derive bounds (I2 at grammar level). Test: stale numbers after a stackup change on 5 boards.
- **LA19** Margin in dB as the common currency (*combo, S*): margin = 20·log10(limit/spent) for amplitudes, 10·log10 for powers; ΔT ratios for temperature; nH, µV, ppm, K comparable for arbitration (N1 market, N6 ε-tiers). Test: arbitration quality vs hand-tuned weights.
- **LA20** Band-indexed references (*new, S*): a reference serves named bands (analog region DC–10 kHz for the ADC, chassis the ESD band, main plane above f_x); star, hybrid, multipoint = band assignments. Test: 10 published grounding schemes compile to their known-good layouts.

## C. Physics graph and views

- **LA21** Partial elements as the accounting unit (*sharp, M*): attribute loop-L spend to segments with partial self/mutual terms (Paul/Ruehli), mutual terms as separate "interaction" rows ("C10 ESL+pads 0.28 nH, vias 0.19 nH, lateral 0.25 nH, interaction −0.05 nH"). Test: vs FastHenry leave-one-out ablation, 5 hot loops.
- **LA22** Port macromodels per cell (*combo, M*): Kron-reduce the physics graph to each cell's ports per band → passive SPICE subcircuit or Touchstone; circuit view gives V_pk, ringing, PDN impedance. Language contract for XD28. Test: reduced vs full at 5 frequencies, < 5% error.
- **LA23** Named, versioned view transforms (*new, S*): `extract`, `reduce`, `expand`, `back_annotate`, `synthesize` are versioned; each ledger number cites transform + model. Test: regenerate ledger from geometry, compare hashes; diff after solver upgrade.
- **LA24** Field tiles for the LLM and VLM (*combo, M*): per-band rasters of J, near-field B_z, E, T at fixed resolution with entity-id overlays ("where is J > 1% of the digital return in AGND?"). Test: VLM seeded-fault accuracy, tiles vs plain renders (U5/V3).
- **LA25** Halos as derived geometry (*sharp, S*): per victim class, contour around an aggressor where the coupling budget is met → rule area + placer repulsion + glyph; RG53, XD68 compute it; plane image matters ([mutual-L table](../../topics/physics/vocabulary.md#why-net-trace-via-and-pour-are-not-enough)) [C]. Test: halo conflicts vs "20 mm from the SMPS" on 10 boards.
- **LA26** Moment with image replaces loop area (*new, S*): budget effective magnetic moment (I·A incl. plane image) and multipole order ([vocabulary](../../topics/physics/vocabulary.md#why-net-trace-via-and-pour-are-not-enough)) [C]; "fold", "cancel" change the order. Test: 30 hot loops ranked by moment, area, openEMS near-field.
- **LA27** Operator previews from low-rank updates (*combo, M*): predicted Δmargin per candidate operator by adjoint/low-rank update of the reduced model in ms (maths XD51). Test: error vs full re-extraction on 100 applications.
- **LA28** One electrothermal graph (*combo, M*): thermal conductances share bodies with the electrical graph, coupled by I²R; `widen_to_pour` reports ΔR and ΔT; thermal-EMF uses the same T. Checks: RG50. Test: ΔT vs Elmer, 5 power boards.
- **LA29** Physics digest for context (*new, S*): board as entities + top ledger rows in ≤ 2k tokens ("18 loops, 3 over budget; 7 couplings, 1 over; 2 antennas"), never copper. Test: repair success and tokens vs geometry dump, 30 tasks.

## D. Operators

- **LA30** Operator sensitivity cards (*new, S*): per operator: affected budgets, sign, magnitude model, cost (area, vias, fab class), preconditions; LLM menu ranked by Δmargin/cost. Test: S5-style refactorings, cards vs free-form choice.
- **LA31** Refuse net-negative operators (*sharp, S*): with per-budget signed effects (LA4), hide operators net-negative across their budgets (e.g. widening a body that is mostly SW node). Test: harmful applications prevented in logged repair loops.
- **LA32** Off-board operators (*new, S*): `slow_edge`, `thin_dielectric`, `swap_package` (lower ESL), `swap_pins`, `move_frequency` propose schematic/stackup changes; e.g. thinner dielectric under the AN-139 loop ([hot-loops](../../topics/rules/power/hot-loops.md)) [P]. Test: share of over-budget cases whose best fix is off-board.
- **LA33** Kelvin by construction (*sharp, S*): `kelvin_tap` → KiCad net-tie footprint at the tap, "K" glyph, checker J = 0 on the sense path; makes TI's net-tie advice ([current-sense-kelvin](../../topics/rules/power/current-sense-kelvin.md)) the default. Test: tap error on 20 shunt boards before/after.
- **LA34** `split_band` operator (*new, S*): DC tie (net tie) + HF cap sites for a band-split reference; only parameter = crossover frequency. Test: noise on 5 analog/digital ground cases vs single plane and hard split.
- **LA35** `cancel` operator (*new, M*): split a loop into counter-rotating halves (two input caps either side of the switch pair) → quadrupole far field; one-word choice with predicted moment (XD11 explores figure-8 loops). Test: `vo_numbers.py` dipole sums + openEMS near-field, 3 GaN cells.
- **LA36** `void` as a designed discontinuity (*sharp, S*): planned cut-outs under RF match pads, AC-coupling cap pads, TIA IN− carry purpose + budget; match-pad C alone costs return loss ([feed](../../topics/physics/physics-ir-examples.md#5-24-ghz-antenna-feed-soc--π-match--chip-antenna)) [C]; critics stop flagging it. Test: false RET-COV removed on 10 RF/high-speed boards.
- **LA37** Operator scripts with physics postconditions (*sharp, S*): S5 refactorings roll back if a protected budget loses margin. Test: "move the USB block to the other edge" with/without.

## E. LLM interface and authoring

- **LA38** Datasheet prose → entities (*combo, S*): extraction targets typed entities, not mm ("keep the CIN–Q1–Q2 loop small" → commutation loop + V_pk budget; "FB divider close to FB pin" → sense port + capacitive coupling budget). Test: 50 datasheet sections, entity P/R vs expert, mm-hallucination rate.
- **LA39** Mechanism hypotheses as the LLM's main write (*new, S*): LLM adds what the screen cannot see ("heatsink is a capacitor to chassis", "TC connector makes a thermocouple with board copper", "cable shield bonds at J4, not J1") as Coupling/Antenna entities with mechanism + band; code quantifies. Test: post-mortem failures missed by the screen but caught by hypotheses.
- **LA40** Questions ranked by ∂margin/∂unknown (*combo, S*): unknowns generate questions ordered by margin impact (U3 with physics), e.g. "gate-driver sink current?" sets di/dt → hot-loop V_pk margin. Test: order vs expert on 10 briefs.
- **LA41** Slogan-to-entity translator (*sharp, S*): user/source slogans ("keep away", "3W", "solid ground", "short and wide") → proposed entity with derived numbers, confirmed by the user; RG49 detects slogans in LLM output, LA41 converts input. Test: user study, encode time and errors.
- **LA42** Physical-unit intent diffs (*sharp, S*): extend I6: diffs in entity/margin units ("buck1.hot V_pk margin −4 dB; new antenna J1↔J4"). Test: I6 seeded-regression protocol.
- **LA43** Stable entity ids across ECOs (*sharp, S*): ids from cell, template, role (`buck1.hot`, `usb.sstx.t_conn`), not refdes. Test: survival after re-annotation and 10 refactorings.

## F. Human and visual

- **LA44** Glyph language from the ledger (*sharp, S*): loop polygons filled by budget use, per-band return ghosts, node halos, mechanism-lettered coupling springs, port dot pairs, antenna halves, "K" taps, budget bars, drawn from the observed graph with ids shared with text ([physics-graph § visual](../../topics/physics/physics-graph.md#visual-vocabulary-board-view-and-vlm-renders)); RG48 renders return current. Test: designer comprehension, VLM seeded-fault accuracy.
- **LA45** Spender bars (*sharp, S*): stacked bar per budget split by spending objects; click selects the object. Test: time to dominant spender vs table.
- **LA46** Sketch-to-entity (*combo, M*): extend U6: lasso a loop, draw a spring, circle a region → proposed entity (loop, coupling, exclusion) with derived budgets. Test: entry time/accuracy vs YAML.
- **LA47** Entity cursor (*new, S*): hover copper → entities it belongs to + spend share ("this via: 19% of buck1.hot L; 0% elsewhere"). Test: "is this via safe to move?" success.

## G. Compilation and verification

- **LA48** Six-target compiler with proxy tags (*sharp, M*): entity → KiCad objects, DRU rules, placer terms, router costs, critics, solver decks; approximating DRU rules carry their derivation (I2); ledger records which target gave the verdict. Test: DRU-proxy vs critic disagreement on 20 boards.
- **LA49** FastHenry and FasterCap decks from entities (*sharp, S*): loop → FastHenry deck cut at its decoupling cap with `.External` across the cut; nodes → FasterCap conductors; solver ports = IR ports, so the half-port rule is shared. Test: 5 EVM hot loops vs published nH (SNVA803, EPC).
- **LA50** Entity stamps in the board file (*sharp, S*): extend I7: component classes `loop:<id>`, rule areas `IR:<id>`, net ties for sense ports, glyph outlines on a User layer. Test: entities rebuilt from stamps after deleting the sidecar.
- **LA51** Mutants per entity kind (*sharp, S*): V1 by kind (break a return, add a via to a hot loop, move a Kelvin tap, bridge a barrier, copper in an antenna keep-out); each critic must kill its kind's mutants. Test: mutation score per kind.
- **LA52** Physics IR as a dataset format (*new, M*): extract entities + observed ledgers from open boards → priors ("achieved L_loop for 1 MHz, 3 A bucks: median X nH") for default budgets and spend-model calibration ([measured-priors](../../topics/data/measured-priors.md)). Test: 100 boards, spread per cell type.
