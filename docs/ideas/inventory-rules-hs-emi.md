# Idea inventory: high-speed, SI, EMC, stackup and interface rules

This is every distinct approach, checker algorithm, design idea and recommendation found in:
- `rules_highspeed_emi.md`, tagged [HS];
- `interface_rule_packs.md`, tagged [IF];

Each idea is one line and links to the topic doc that holds its detail and sources.

## Physics and modelling
1. Encode physics, not slogans; store myths as negative rules with the check that replaces them [HS]. [myths](../topics/rules/myths-and-contested.md)
2. Return current flows directly under the trace, so every fast net needs a continuous reference plane [HS]. [si](../topics/rules/si-fundamentals.md)
3. The ±1h/±3h/±10h return spread justifies edge and void offsets (1.5W ≈ 3h) [HS]. [si](../topics/rules/si-fundamentals.md)
4. A via passing through the same plane is not a discontinuity; don't flag it [HS]. [si](../topics/rules/si-fundamentals.md)
5. Merge antipads into void polygons and measure slot length perpendicular to the trace [HS]. [checkers](../topics/rules/checkers-si-emi.md)
6. Use Ott's 4-level layer-change order as the router's policy [HS]. [si](../topics/rules/si-fundamentals.md)
7. Place return vias within 200 mil, tightened with data rate (~5 / 2.5 / 1.3 mm) [HS][IF]. [si](../topics/rules/si-fundamentals.md)
8. Use stitching caps (≤1 µF) only at unavoidable split crossings; "1–10 nF within 50 mil" is not primary [VR]. [si](../topics/rules/si-fundamentals.md)
9. Avoid power-plane references; never overlap planes that do not reference each other [HS]. [si](../topics/rules/si-fundamentals.md)
10. On boards with planes, use no ground traces or fill; connect grounds with direct vias [HS]. [si](../topics/rules/si-fundamentals.md)
11. Aim for a 10:1 signal:ground via ratio (Johnson's 3-D scaling) [HS]. [si](../topics/rules/si-fundamentals.md)
12. Differential pairs return under each leg, so apply the return-path rules to each leg [HS]. [diff](../topics/rules/diff-pairs.md)
13. Skew becomes common mode: 20% skew gives 10% CM (Johnson) [HS]. [diff](../topics/rules/diff-pairs.md)
14. Critical length: flag for SI review at t_r/6; terminate at t_r/2 (contested) [HS][VR]. [si](../topics/rules/si-fundamentals.md)
15. Slow edges first; default to a series R; target a transition time of ≈20% of the UI [HS]. [si](../topics/rules/si-fundamentals.md)
16. Choose termination values that minimise harmonic current, not ones that merely look good in voltage (Archambeault) [HS]. [si](../topics/rules/si-fundamentals.md)
17. Stub limit = min(15 mil, 0.3/Gbps), counting the pad rings [HS][VR]. [si](../topics/rules/si-fundamentals.md)
18. Decide the stub strategy (backdrill, near-outer layers, blind vias) before the stackup [HS]. [stackup](../topics/rules/stackup.md)
19. Enter connector pads from the non-stub end; enter TH receptacles from the bottom [HS][VR]. [si](../topics/rules/si-fundamentals.md)
20. Model crosstalk with Johnson's K = 1/(1+(D/H)²), with saturation and a sum over aggressors [HS]. [si](../topics/rules/si-fundamentals.md)
21. Set spacing from a crosstalk budget: D ≥ H·√(1/K−1) [HS]. [si](../topics/rules/si-fundamentals.md)
22. Reduce crosstalk through lower h (the stackup) before adding spacing [HS]. [stackup](../topics/rules/stackup.md)
23. Guard traces only in stripline, end-shorted and length-matched; never in microstrip [VR]. [myths](../topics/rules/myths-and-contested.md)
24. Apply stricter crosstalk budgets to I/O and analog victims [HS]. [si](../topics/rules/si-fundamentals.md)
25. Route adjacent signal layers orthogonally [VR]. [si](../topics/rules/si-fundamentals.md)
26. Use LearnEMC's three-condition antenna model, with 1 mV (or 100 µV) between antenna parts as the limit [HS]. [emc](../topics/rules/emc-placement.md)
27. Use the MREMC algorithm as a computable common-mode EMI estimator [HS]. [emc](../topics/rules/emc-placement.md)
28. Use Ott's DM and CM radiation formulas and his 5/15 µA cable-current limits [HS]. [emc](../topics/rules/emc-placement.md)
29. Use the FCC 15.109 limits as the target for E_max [HS]. [emc](../topics/rules/emc-placement.md)
30. Cross-check consistency between 1 mV, 3.6 µA and the Class B limit [HS]. [emc](../topics/rules/emc-placement.md)
31. Use the cavity-resonance formula for the stitching checker [HS]. [checkers](../topics/rules/checkers-si-emi.md)
32. Never use a spread-spectrum clock as a reference for transceivers, PLLs or RF [HS]. [clocks](../topics/rules/crystals-clocks.md)
33. Treat every pin of a fast IC as a potential HF source [HS]. [emc](../topics/rules/emc-placement.md)

## Differential pairs
46. skew_max = min(spec, 0.1·t_r), converted with the per-layer delay [HS]. [diff](../topics/rules/diff-pairs.md)
47. Running-skew compensation near the mismatch, not only at the end of the route [HS]. [diff](../topics/rules/diff-pairs.md)
48. Place ICs so pairs exit and enter in the same direction [HS]. [diff](../topics/rules/diff-pairs.md)
49. Serpentine switchbacks ≪ ⅓ t_r or uncoupled; jogs ≥3W; spread <2S [HS][VR]. [diff](../topics/rules/diff-pairs.md)
50. Coupling tighter than 0.5 mm buys no extra EMI; choose the gap for Zdiff and density [HS]. [diff](../topics/rules/diff-pairs.md)
51. GND vias pinning the planes at each differential via (XFP pattern) [HS]. [diff](../topics/rules/diff-pairs.md)
52. Absolute keep-outs: 30 mil to other signals, 50 mil to clocks [VR]. [diff](../topics/rules/diff-pairs.md)
53. Uncoupled length ≤45 mil; breakout within 0.25 in [VR]. [diff](../topics/rules/diff-pairs.md)
54. Equal via counts on both legs; via limits scoped to the device family [VR]. [diff](../topics/rules/diff-pairs.md)
55. 30 mil antipads; no non-functional pads [VR]. [diff](../topics/rules/diff-pairs.md)
56. Symmetric 0402 in-line parts with 100%, 2-layer-deep pad voids [VR][IF]. [diff](../topics/rules/diff-pairs.md)
57. Bends >135°, with balanced left and right turns [VR][IF]. [diff](../topics/rules/diff-pairs.md)
58. KiCad pair-to-pair clearance condition `A.inDiffPair('*') && !AB.isCoupledDiffPair()` [HS]. [diff](../topics/rules/diff-pairs.md)
